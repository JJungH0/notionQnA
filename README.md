# Programming 퀴즈 (Notion Quiz)

내 노션 "Programming" 위키의 노트를 읽어 주제별 Q&A 퀴즈를 자동으로 만들고 점수를 매기는 웹 앱입니다.
AI나 API 키 없이, 노트의 작성 규칙(인용 = 주제, 콜아웃 안의 토글 = 소제목, → 설명)만으로 문제를 만듭니다.
Node.js 18 이상만 있으면 별도 설치 없이 실행됩니다.

## 실행

```bash
cd notion-quiz
node server.js
```

브라우저에서 <http://localhost:3000> 을 열면 주제 목록(HTTP, CS, GitHub, Spring JPA …)이 나옵니다.
주제를 누르면 하위 페이지까지 읽어 문제를 만들고, 유형(단답/서술)·문제 수·순서를 고른 뒤 시작합니다.

- 노션 링크는 `server.js` 상단의 `ROOT_URL` 에 고정되어 있습니다. 다른 위키를 쓰려면 이 값만 바꾸면 됩니다.
- 포트 변경: `PORT=4000 node server.js`

## 문제가 만들어지는 규칙

노트 구조 `인용(주제) → 콜아웃 → 토글/글머리(소제목) → "→ 설명" 줄` 을 다음 규칙으로 변환합니다.

| 노트 형태 | 만들어지는 문제 | 유형 |
| --- | --- | --- |
| 인용이 질문문 (`JPA의 DDL-AUTO란?`) | 인용 그대로 → 본문이 정답 | 서술형 |
| `약어 (= 원어)` (`DNS (= Domain Name System)`) | "DNS의 풀네임은?" / "Domain Name System을 줄여 부르는 용어는?" | 단답형 |
| `용어 (= 한글 설명문)` (`TCP (= 데이터를 주고받기 위한 기본 통신 규약)`) | "TCP란? (한 줄로 설명)" / "…을 가리키는 용어는?" | 단답형 |
| `정의 :` 토글 | "'포트'의 정의는?" → 토글 내용 | 서술형 |
| 소제목이 용어 + 설명 한 줄 (`Commit` → `→ 파일의 변경 사항을 저장`) | "[GIT 핵심 개념] Commit이란?" → 설명 | 단답형 |
| 소제목이 용어 + 설명 여러 줄 (`클래스 (= Class)` → 설명들) | "[소프트웨어 설계] 클래스란?" → 설명 전체 (영어 표기는 참고로만 표시) | 서술형 |
| 그 외 소제목 (`특징 :`, `단점 :`) | "[싱글톤 패턴] 단점이란?" → 하위 내용 전체 | 서술형 |
| `→ 항목 - 설명` 줄 (`→ A - IPv4주소 매핑`) | "[DNS · 레코드 종류] A는?" → "IPv4주소 매핑" | 단답형 |

정답은 항상 **설명**이 되도록 합니다. `싱글톤 패턴 (= Singleton Pattern)`, `즉시 로딩 (= EAGER)` 처럼 한글 용어의 영어 표기만 있는 것은 단순 번역이므로 문제로 만들지 않습니다.
코드 블록, 이미지, 표는 문제에서 제외합니다. 제목만 있는 목차 페이지는 하위 페이지를 따라 들어가서 읽습니다(최대 2단계).
규칙을 바꾸면 `server.js` 의 `RULES_VERSION` 을 올려 옛 캐시를 무효화합니다.

## 채점 방식

- **단답형**: 띄어쓰기·문장부호를 무시하고 유사도 75% 이상이면 정답. `A / B`, `A, B` 형태의 복수 정답 허용.
- **서술형**: 정답에서 핵심 단어를 뽑아 내 답에 얼마나 포함됐는지로 채점(핵심어 수에 따라 40~67% 기준). 적중한 핵심어와 빠진 핵심어를 색으로 표시합니다.
- 채점이 틀렸다고 판단해도 **맞은 것으로 처리** 버튼으로 직접 인정할 수 있습니다.
- 주제별 최고 점수는 브라우저에 저장되어 주제 카드에 표시됩니다.

## 구조

- `server.js` : 노션 비공식 API(`loadPageChunk`, `queryCollection`, `syncRecordValues`)로 공개 페이지를 읽고 규칙 기반으로 문제를 생성하는 서버. 429 재시도, 동시 요청 3개 제한, 결과를 `.cache.json` 에 6시간 캐시.
- `public/index.html` : 퀴즈 화면 (주제 목록 → 설정 → 문제 풀이 → 결과). 다크 테마 단일 파일이며 Pretendard 웹폰트(CDN)를 쓰고, 오프라인이면 시스템 글꼴로 대체됩니다.

## 참고

- 노션 비공식 API는 `User-Agent` 헤더가 없으면 403을 반환합니다.
- 노션 내용을 수정한 뒤에는 주제 목록의 "노션 다시 읽기" 또는 `/api/quiz/<id>?refresh=1` 로 캐시를 갱신할 수 있습니다.
